# Grill the owner on where the tab-per-ticket TC writer may live, given the sheet write rule

## Question

เจ้าของเลือก (popup 15 Oct 2026) "เพิ่มขั้นนี้เข้าสกิลใน ols-qa" แต่กฎของเรโป ols-qa ห้ามเขียน tab TC ผ่าน Sheets API เอง (ไฟล์ references/ols-project-guide.md บรรทัด 183 ของเรโป ols-qa: "เขียนผ่าน sheet_write.py ... ห้ามยิง Sheets API เขียน tab TC เอง") และ `sheet_write.py` ใน `~/ols-qa-testing-bot` เขียนได้แค่ผลเทสในแถวที่มีอยู่แล้ว สร้าง tab ไม่ได้ · agent หยุดไว้ ไม่ได้สร้างอะไร · ทางเลือก:
1. เพิ่มโหมดสร้าง tab แบบมี guard ใน `sheet_write.py` ของเรโป ols-qa-testing-bot (แตะอีกเรโป) แล้วให้สกิลใน ols-qa เรียกใช้
2. เจ้าของแก้กฎในคู่มือให้ระบุเครื่องมือใหม่ใน ols-qa สำหรับสร้าง tab ใหม่เท่านั้น
3. ทำแค่ตัวสร้าง payload และเทสต์ใน ols-qa แบบ dry-run ให้คนกดเขียนเอง

ถามทาง DM Slack ตามกฎ 2a3 เมื่อเจ้าของตื่น

## Resolution

ปิดด้วยทางเลือกที่ 1 คือเพิ่มโหมดสร้าง tab แบบมี guard ใน `sheet_write.py` แล้วให้สกิลใน ols-qa เรียกใช้ · ที่มาของการตัดสิน: เจ้าของ 15 Oct 2026 "หาทางจัดการมา ไม่ใช่รอแต่เรา" และทางเลือกที่ 1 ซึ่ง agent ที่สืบรอบก่อนแนะนำไว้ เพราะยังคงมีผู้เขียน tab TC เพียงรายเดียวตามกฎในคู่มือ

- PR ใน ols-qa-testing-bot: https://github.com/Thitic9203/ols-qa-testing-bot/pull/5 · คำสั่ง `sheet_write.py --create-tab <KEY> --rows <csv หรือ json>` สร้าง tab ที่ชื่อตรงกับ key ใส่หัว 16 คอลัมน์แบบ OLS-44 เขียนแถวแบบ `RAW` และสร้าง Table ที่ dropdown คัดลอกจาก tab OLS-44 ตอนรัน · ปฏิเสธถ้ามี tab ชื่อนี้อยู่แล้ว · ไม่แตะ Test Progress · อ่านกลับผ่าน `sheet_guard.py` · เทสต์ออฟไลน์ผ่านครบ 19 ข้อ
- PR ใน ols-qa: https://github.com/Thitic9203/ols-qa/pull/36 · ขั้น 6.5 ของสกิล tc-fe-prep เรียกคำสั่งนี้หลังร่างได้รับอนุมัติ (สำหรับ agent คือเจ้าของตอบ `passed` ใน DM Slack) โดยรัน `--dry-run` ก่อนแล้วจึงเขียนจริง · คู่มือโปรเจกต์ระบุโหมดใหม่ไว้ในแถว Write scope · ไม่ได้เพิ่มขั้นนี้ใน tc-api-prep เพราะคอลัมน์ของเทสเคส API ไม่ตรงกับ 16 คอลัมน์ OLS-44
- เจ้าของเป็นคน merge เอง โดย merge PR ของ ols-qa-testing-bot ก่อน แล้วจึง merge PR ของ ols-qa
- ยังไม่ได้ทดสอบกับชีทจริง: ต้องรัน `--dry-run` แบบออนไลน์ แล้วรันจริงกับ key ทดลองหนึ่งครั้ง
