# Prototype the project label on each lane card in AI Agent Home Office

## Question

ลาเบลเล็กมุมขวาของการ์ดงานในเลน บอกโปรเจกต์ (เช่น `pluton-timesheet`, `OLS`) ตามที่เจ้าของบอก "อาจจะเป็น ลาเบลเล็กๆ มุมขวา ในการ์ดงานที่อยู่ในเลน" · ลองในหน้า artifact ด้วยข้อมูลจำลองที่มีงาน OLS ปนอยู่ ทั้งสองธีมและสามความกว้าง contrast ผ่านเกณฑ์ · คนบนแมปและ roster บอกโปรเจกต์ที่กำลังทำด้วยหรือไม่ ให้เจ้าของดูแล้วตัดสิน · ทำหลังงานอัปเกรดภาพที่กำลังแก้ไฟล์เดียวกันเสร็จ

## Resolution

ปิดแล้ว: ลาเบลโปรเจกต์ขึ้นบนการ์ดงานทุกใบในหน้า Agent Office ตั้งแต่ v58 และยังอยู่ใน v60 (artifact https://claude.ai/artifact/Wp7pFHwNt9jDjkPZPctVjG) · เจ้าของดูแล้วตัดสินผ่านคอมเมนต์บน artifact 14 Oct 2026 "ต้องมีลาเบล ชื่อโปรเจ็คทุกงานนะ บังคับ"

- การ์ดทุกใบตั้งค่า `.pchip` จาก `projectOf(i)` ซึ่งถอยไปใช้โปรเจกต์ตั้งต้นเมื่อใบงานไม่ระบุ การ์ดจึงไม่มีใบที่ไม่มีลาเบล · รอบ release ไม่ปนโปรเจกต์ และมีแท็บ "โปรเจกต์"
- contrast (WCAG 2.x, คำนวณจาก token ในหน้า 15 Oct 2026): Taskfolio สว่าง 5.38 มืด 4.82 · OLS สว่าง 7.46 มืด 7.83 ผ่าน 4.5:1 ทุกคู่
- ลาเบลครบอยู่ในรายการตรวจของ v60 (แผนแม่ข้อ 9a) · ลาเบลไม่ตัดบรรทัด (`white-space: nowrap`)
