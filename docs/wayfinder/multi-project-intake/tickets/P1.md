# Research the OLS Jira fields, statuses and the query that finds the owner's QA work

## Question

ใน Jira โปรเจกต์ OLS: field "QA Owner" คือ custom field ตัวไหน (id), ชื่อสถานะจริงที่ตรงกับ "ready to test" (RTT), "Testing" และ "Done" ใน workflow ของแต่ละ issue type (Story, Bug, Task, Sub-task), และ JQL ที่ได้ชุดใบตามกฎรับงานใน Notes ของแมพ ("ทุกใบที่ ready to test และอยู่ชื่อเรา หรือ ใบไหนก็ตาม ที่ QA Owner เป็นเรา และสถานะยังไม่ done") · อ่านอย่างเดียว ห้ามเขียน Jira · ผลต้องมี JQL ที่รันแล้ว จำนวนใบที่ได้ และตัวอย่าง key 3 ใบ (ไม่คัดลอกเนื้อหา ticket ลงเอกสาร)

## Resolution

รายละเอียดอยู่ใน [P1-findings](../research/P1-findings.md)

- field QA Owner คือ `customfield_12120` (people picker เลือกได้หลายคน) มีใน Story, Bug และ Task · Subtask ไม่มีใครตั้ง QA Owner เลย
- ทุก issue type ใช้ 8 สถานะเดียวกัน: To Do, In Progress, REVIEWING, DEPLOYING, READY TO TEST, TESTING, BLOCKED, Done · **READY TO TEST อยู่หมวด To Do** ถ้ากรองด้วย `statusCategory = "In Progress"` จะหลุด · Done เป็นสถานะ done เดียว
- JQL ตามกฎรับงาน (อ่าน "อยู่ชื่อเรา" เป็น assignee) ได้ 0 ใบ ณ 14 Oct 2026 เพราะใน OLS คนเทสอยู่ที่ QA Owner ไม่ใช่ assignee · เจ้าของเป็น QA Owner 200 ใบรวมทุกสถานะ
- สัญญาณว่ามีเทสเคสแล้ว: field `TC Status` (`customfield_12128`) และ field กลุ่ม TC/regression อื่น
- คำถามส่งต่อให้ P3: "อยู่ชื่อเรา" คือ assignee หรือ QA Owner · ใช้ `TC Status` ตัดสินว่ามีเทสเคสแล้วได้ไหม ค่าไหนนับ · Subtask อยู่ในขอบเขตไหม
