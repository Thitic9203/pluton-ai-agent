# Grill the owner on the QA flow per ticket type: the sheet, TC review and result review

## Question

Google Sheet ของ QA คือไฟล์ไหน รูปแบบแถวเทสเคสเป็นอย่างไร ("ยังไม่มีเทสเคส" ตรวจจากอะไร) · รีวิวเทสเคสและรีวิวผลเทสเกิดเมื่อไรและใครทำ (เช่น QA Lead รีวิวงาน QA) · ลำดับเต็มของ story หนึ่งใบตั้งแต่เขียนเทสเคสจนเทสเสร็จ และของ bug หรือ task ตั้งแต่รับจนรีเทสเสร็จ รวมจุดที่ส่งร่างเข้า DM Slack รอ `passed`

## Resolution

คำตอบเจ้าของ (popup 14 Oct 2026):

- **"อยู่ชื่อเรา":** "QA Owner อย่างเดียว" กฎรับงานใช้ field QA Owner (`customfield_12120`) = เจ้าของ ไม่ใช้ assignee
- **มีเทสเคสแล้ว:** "ได้ DONE หรือ QA REVIEWED = มีแล้ว" ใช้ field TC Status (`customfield_12128`) ค่าอื่นนับว่ายังไม่มี
- **รีวิวเทสเคส:** "QA Lead agent แล้วส่ง DM ให้เรา passed" QA Lead agent รีวิวด้วยสกิล `tc-review-workflow` แล้วส่งร่างเข้า DM Slack ตอบ `passed` จึงเปลี่ยนเป็น QA Reviewed
- **ที่เขียนเทสเคส:** เจ้าของ: "สกิลเดิมเขียนในชีท qa ที่สร้าง tab ใหม่ต่อหนึ่งทิคเกตแล้วทำตารางใส่รายละเอียด" ผลค้นของ P2 ไม่พบขั้นนี้ จึงยังต้องหาว่าโค้ดหรือเอกสารส่วนนี้อยู่ที่ไหน (ทำต่อใน P9)
