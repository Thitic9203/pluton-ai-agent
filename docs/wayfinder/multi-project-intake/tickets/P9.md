# Research where the existing TC skill creates a sheet tab per ticket

## Question

เจ้าของยืนยันว่าสกิลเขียนเทสเคสเดิม "เขียนในชีท qa ที่สร้าง tab ใหม่ต่อหนึ่งทิคเกตแล้วทำตารางใส่รายละเอียด" แต่ P2 ไม่พบ · หาโค้ด สคริปต์ หรือเอกสารที่ทำขั้นนี้ (เรโป ols-qa ทุก branch, `~/ols-qa-testing-bot`, สกิลใน `~/.claude/skills` และ plugin cache) ระบุ: ชื่อ tab ตั้งอย่างไร, หัวตาราง, ใช้ credential อะไร (ชื่อเท่านั้น), และเรียกจากขั้นไหนของสกิล · อ่านอย่างเดียว

## Resolution

รายละเอียดอยู่ใน [P9-findings](../research/P9-findings.md)

- ตัวสร้าง tab ต่อ ticket ไม่ได้อยู่ในสกิล แต่อยู่ในสคริปต์ `write_tabs.py` ของโฟลเดอร์ `~/ols-qa-tc-autodraft-bot` (ไม่ใช่ git repo) ใช้ `addSheet` ตั้งชื่อ tab เป็น key ของ ticket เช่น OLS-290 และใส่หัวตาราง 16 คอลัมน์แบบ OLS-44
- เรียกจาก bot ตั้งเวลา (launchd `com.thitichaya.ols-tc-autodraft` ทุก 4 ชั่วโมง ปิดไว้ตั้งแต่ 25 Jul 2026) และจาก session ที่เจ้าของสั่งเอง ("สร้าง tab สำหรับทิคเกตนี้ และใช้ฟอแมตเหมือน OLS-44")
- ปัญหาถ้าใช้ซ้ำ: ค่า status ไม่ตรง dropdown, เขียนแบบ `USER_ENTERED` แต่คู่มือกำหนด `RAW`, ไม่สร้าง Table และ dropdown, เขียน tab Test Progress ซึ่งคู่มือให้ `progress_build.py` เขียนเท่านั้น, sheet ID ฝังในโค้ด
- ต่อไป: ขั้นเขียนเทสเคสของ agent ต้องสร้าง tab แบบ OLS-44 ให้ครบ (Table, dropdown, `RAW`) และไม่แตะ Test Progress ส่วนจะแก้ `write_tabs.py` หรือเพิ่มขั้นในสกิลของเรโป OLS-QA ให้ถามเจ้าของทาง DM Slack
