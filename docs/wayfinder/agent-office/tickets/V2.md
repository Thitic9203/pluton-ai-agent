## Question

ควรวาดออฟฟิศ isometric ด้วยวิธีใด (SVG tile ทำเอง, canvas 2D กับ sprite sheet, ไลบรารีอย่าง PixiJS หรือ Phaser, หรือ CSS 3D) ให้ลื่นบนมือถือ เข้าถึงได้ด้วย screen reader (ตัวละครและสถานะต้องมีเป็นข้อความจริงด้วย) และทำกลางวันกลางคืนได้ และใช้ asset ฟรีชุดไหนที่ license อนุญาตให้ใช้ในเครื่องมือภายในโดยไม่มีปัญหาเรื่อง attribution รวมถึงยืนยันว่า GSAP ใช้ฟรีภายใต้เงื่อนไขปัจจุบัน

## Resolution

**เปลี่ยน 14 Oct 2026 (เจ้าของ popup: "เปลี่ยนเป็น 3D จริง"):** วาดออฟฟิศเป็น 3D จริงด้วย Three.js (ฟรี MIT โหลดจาก CDN หมุนกล้องได้) แทน SVG isometric ด้านล่าง · ป้ายชื่อและสถานะยังเป็น HTML ซ้อนบน, รายชื่อทีมยังเป็นข้อความจริงให้ screen reader, GSAP ยังใช้กับการเดินของตัวละครและปิดเมื่อ reduce motion · Phaser, Blender และบริการสร้างภาพยังห้ามเหมือนเดิม

หลัก: SVG isometric ที่วาดเอง (ไม่มี license ต้องติดตาม) ป้ายชื่อและสถานะเป็น HTML จริงซ้อนด้านบนให้ screen reader อ่านได้ กลางวันกลางคืนสลับด้วย CSS variable และชั้นสี `mix-blend-mode: multiply` แอนิเมชันใช้ `gsap.matchMedia()` ที่ปิดเองเมื่อ reduce motion · GSAP ใช้ฟรี รวมงานเชิงพาณิชย์
สำรอง: canvas 2D กับ sprite ของ Kenney (CC0)
ตัดออก: PixiJS และ Phaser หนักเกินงาน (215 KB และ 315 KB gzip), CSS 3D เสี่ยงบนมือถือ, LimeZu เสียเงินและต้องให้เครดิต
